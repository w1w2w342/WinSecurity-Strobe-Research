# WinSecurity-Strobe-Research

**WinSecurity-Strobe-Research** — исследовательский программный комплекс на Python, моделирующий логику работы экранного блокировщика (Winlocker) под видом утилиты системной безопасности «SystemDefender». Проект разработан в демонстрационных и образовательных целях для анализа механизмов перехвата пользовательского ввода, взаимодействия с системным реестром Windows и манипуляций графической подсистемой рабочего стола.

---

## 1. Концепция и архитектура исследования

* **Назначение:** Практический анализ методов закрепления в операционной системе (Persistence), изоляции интерфейса пользователя, рендеринга видеопотока в безрамочном окне и вызова нативных API Windows через C-типы.
* **Сценарий выполнения:**
  * **Инициализация автозагрузки:** При первом старте процесс прописывает путь к исполняемому файлу в ветку текущего пользователя системного реестра.
  * **Блокировка окружения:** Создается полноэкранное окно с наивысшим Z-order поверх панели задач, после чего перехватываются критические комбинации системных клавиш.
  * **Мультимедийный цикл:** Запускается параллельный рендеринг зацикленного видеоряда и синхронное воспроизведение звуковой дорожки через нативный медиа-интерфейс Windows.
  * **Валидация доступа:** Отображается поле ввода пароля. Успешный ввод снимает блокировку экрана, но активирует цикл высокочастотной смены обоев рабочего стола.

## 3. Механики работы и системные хуки

* **Подавление стандартных средств завершения:**
  * Переопределен системный протокол `WM_DELETE_WINDOW`.
  * Реализован хук для перехвата комбинации `Alt+F4` и служебных клавиш навигации Windows.
* **Контур авторизации:**
  * Интерфейс содержит форму ввода ключа деактивации. Валидным значением по умолчанию является код `67`.
* **Фоновый пост-эффект («Стробоскоп»):**
  * После корректного ввода пароля окно блокировщика сворачивается, перехват клавиатурных событий деактивируется, а MCI-интерфейс останавливает воспроизведение звука.
  * Процесс не завершается: в фоновом потоке-демоне (`threading.Thread(daemon=True)`) запускается таймер с интервалом `0.05` секунды, циклически передающий дескрипторы изображений в функцию `SystemParametersInfoW`, создавая визуальный эффект стробоскопа на рабочем столе.
